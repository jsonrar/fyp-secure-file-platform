# 项目范围

[English](PROJECT_SCOPE.md) | 简体中文

## 最终产品

一个安全文件加密与共享平台：可信客户端生成并控制用户私钥和文件加密密钥；后端保存客户端
加密的密文、公钥、口令保护的私钥信封、每个接收者专属的文件密钥包装、访问策略、恢复工作流
状态，以及可检测篡改的审计证据。

## 范围内

- 用户注册、登录、不透明服务端会话及基于角色的访问控制
- 登录密码与仅客户端使用的加密 passphrase 分离
- 客户端生成 RSA 公钥/私钥对
- 使用 Argon2id 派生 KEK，包装随机账户主密钥（AMK）
- 使用 AMK/HKDF 派生密钥及 AES-256-GCM 加密 PKCS#8 私钥包
- 客户端使用独立随机 DEK 和 AES-256-GCM 加密文件
- 有界密文上传、存储、下载、删除及 SHA-256 完整性检查
- 为每个获授权用户使用 RSA-OAEP-SHA256 包装 DEK
- 客户端重包装 DEK 以进行共享，以及撤销未来访问
- 密钥保护配置取回，以及同时受乐观 revision 和最新当前私钥 RSA-PSS-SHA256 授权保护的
  passphrase 重包装
- 由当前私钥授权的后继密钥添加，并保留历史密钥包
- 恢复公钥登记/轮换，以及上传时强制创建恢复包装
- 有时限、经办-复核的恢复请求，以及隔离离线/HSM 的 DEK 解包/重包装
- 范围化审计查询及串行化的可检测篡改审计哈希链
- 管理员用户/文件列表及账户启用/禁用控制
- MySQL/Alembic Schema 交付、生产 SQL 奇偶校验及就绪 revision 检查

## 范围外

- 恢复或由服务器重置遗忘的加密 passphrase
- 服务端解密用户私钥、文件 DEK 或文件内容
- 元数据匿名：当前契约中，服务器可以看到文件名、MIME、大小、时间戳、所有权及共享关系
- 在没有客户端指纹/revision 固定或独立信任锚时防御主动恶意服务端
- 类似 Google Drive 的在线文档协作或实时多用户编辑
- 大规模云存储优化，或对 1 GB 以上文件的性能保证
- 强制删除撤销前已经复制的密文、DEK 或明文
- 加密全文搜索、水印及 DRM/不可移除内容控制
- 生产级 KMS/HSM 实现或自动化离线恢复工作站
- 忘记登录密码重置、邮箱验证、MFA 及外部身份联合

## 核心限制

用户通常只需记住加密 passphrase，因为服务会保存加密私钥包。如果遗忘该口令，且没有独立
安全保存的备份或恢复因子，则 AMK 和对应私钥在密码学上不可恢复。已实现恢复流程只把文件 DEK
重新包装给一个已经登记的活跃用户公钥，不会恢复 passphrase 或私钥包。

撤销只控制未来通过本平台的下载，无法删除接收者已经取得的数据。

后端可见运营元数据；数据库被盗后，攻击者可对 Argon2id 保护的密钥信封进行离线猜测。因此
必须使用强 passphrase，并根据实际客户端硬件基准选择合适 KDF 参数。

恢复私钥绝不提交给 API。本仓库实现恢复公钥登记及受治理请求协议；真实部署仍须提供隔离离线
或 HSM 托管、操作员认证、洁净日志规则、备份/轮换及经过演练的灾难恢复流程。
