# 项目范围

[English](PROJECT_SCOPE.md) | 简体中文

## 最终产品

一个安全的文件加密与共享平台：使用服务端 AES 加密保护上传的文件，通过
基于 RSA 的密钥包装管理文件访问，支持受控共享与撤销，并通过完整性验证、
恢复治理和可检测篡改的审计日志强化可追责性。

## 范围内

- 用户注册与登录
- 基于角色的访问控制
- 文件上传
- 服务端 AES 加密
- 加密文件存储
- 文件元数据管理
- 为用户生成 RSA 公钥/私钥对
- 为每个获授权用户包装 AES 文件密钥
- 与选定用户共享文件
- 撤销未来下载的访问权限
- 使用 SHA-256 验证加密文件的完整性
- 记录安全敏感操作的审计日志
- 可检测篡改的审计日志哈希链
- 用于例外访问的恢复密钥机制
- 基础管理员控制面板

## 范围外

- 完整的端到端加密
- 类似 Google Drive 的在线文档协作
- 实时多用户编辑
- 大规模云存储优化
- 对超大文件（例如 1GB 以上）的性能保证
- 强制删除撤销前已经下载的文件
- 完全无法移除的水印
- 加密全文搜索
- 生产级 KMS/HSM 集成

## 核心限制

撤销只能阻止今后通过本平台进行的访问。如果用户在撤销前已经下载了明文
副本，系统无法删除该本地副本。

水印用于威慑和追踪。它无法完全防止截图、拍照、文件转换或刻意移除。

恢复机制用于 FYP 演示和治理讨论。在生产环境中，应使用更强的操作控制来
保护恢复私钥。
